# Setting Up Visual Studio Code for Web Development

## 🧩 Overview

Visual Studio Code (VS Code) is a lightweight yet powerful source code editor with support for HTML, CSS, JavaScript, and many other web technologies. This guide covers installation and setup for web development.

---

## 🧱 Step 1: Download and Install VS Code

1. Go to the official website: [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Choose your operating system (Windows, macOS, or Linux).
3. Download the installer.
4. Run the installer and follow the setup wizard instructions.

**Example (Windows Installation):**

* Accept the license agreement.
* Choose installation location.
* Select the options to *Add to PATH* and *Open with Code* for convenience.

![VS Code Installer Screenshot](https://uchicago-cs.github.io/student-resource-guide/_images/install-code-win-2.png)

After installation, open VS Code from the Start Menu or Applications folder.

---

## ⚙️ Step 2: Set Up for Web Development

### 1. Install Essential Extensions

Search and install the following extensions in VS Code (`Ctrl+Shift+X` or `Cmd+Shift+X`):

* **Live Server** – run your HTML files with a live preview.
* **Prettier** – code formatter.
* **Auto Rename Tag** – automatically rename paired HTML tags.
* **CSS Peek** – jump to CSS definitions.
* **ESLint** – maintain clean JavaScript code.
* **HTML CSS Support** – auto-completion for class and id names.

![VS Code Extensions Marketplace](https://code.visualstudio.com/assets/docs/getstarted/extensions/search-for-todo-extension.png)

### 2. Create a Test Web Project Folder

1. Create a folder, e.g., `my-web-project`.
2. Open it in VS Code (`File > Open Folder` or drag-and-drop the folder into the editor or right-click and select `Open with Code`).
3. Create the following basic files:

   * `index.html`
   * `style.css`
   * `script.js`

Folder structure example:

```
my-web-project/
├── index.html
├── style.css
└── script.js
```

![VS Code Project Folder](https://i.ibb.co/BK3kF7kN/Screenshot-2025-10-29-031302.png)

---

## 🚀 Step 3: Run Your First Web Page

1. Open `index.html`.
2. Click **Go Live** (bottom-right corner) to start the **Live Server**.
3. The browser will open automatically showing your page.

If you make changes in the editor, the page refreshes automatically.

![Live Server Running](image-placeholder-live-server.png)

---

## 🧠 Step 4: Customize VS Code Settings

* **Theme:** Try `One Dark Pro` or `Dracula Official` for a better visual experience.
* **Font:** Install and use `Fira Code` or `JetBrains Mono` for ligatures.
* **Settings Sync:** Sign in with GitHub or Microsoft account to sync settings across devices.

![VS Code Theme Customization](https://code.visualstudio.com/assets/docs/configure/themes/additional-color-themes.png)

---

## 🧰 Step 5: Bonus Tools for Web Dev

* **Git Integration:** VS Code includes built-in Git support.
* **Terminal:** Use the integrated terminal (`Ctrl+``) to run commands like`npm install`or`git status`.
* **Emmet:** Type shortcuts like `!` + `Tab` to quickly scaffold HTML.

![VS Code Terminal Example](https://code.visualstudio.com/assets/docs/terminal/getting-started/open-terminal.png)

---

## ✅ You’re Ready

You’ve now installed and configured VS Code for modern web development. You can build, preview, and deploy websites efficiently from this setup.
