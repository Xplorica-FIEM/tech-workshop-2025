# HTML Resources

## 📘 Official Documentation & References

* [MDN Web Docs - HTML](https://developer.mozilla.org/en-US/docs/Web/HTML): Comprehensive documentation with examples and browser compatibility notes.
* [WHATWG HTML Living Standard](https://html.spec.whatwg.org/): The current, continuously updated HTML specification.

## 🎓 Tutorials & Learning Platforms

* [freeCodeCamp - HTML Course](https://www.freecodecamp.org/learn/responsive-web-design/): Hands-on exercises for mastering HTML and responsive design.
* [W3Schools HTML Tutorial](https://www.w3schools.com/html/): Beginner-friendly, interactive examples.
* [Codecademy - Learn HTML](https://www.codecademy.com/learn/learn-html): Guided exercises with in-browser coding.
* [HTML Dog Tutorials](https://htmldog.com/guides/html/): Clear, concise HTML tutorials for all skill levels.

## 🧠 Practice & Interactive Learning

* [Frontend Mentor](https://www.frontendmentor.io/): Real-world projects to build HTML/CSS skills.
* [CodePen](https://codepen.io/): Sandbox for experimenting with HTML, CSS, and JS.
* [JSFiddle](https://jsfiddle.net/): Another live code editor for web projects.
* [Scrimba](https://scrimba.com/): Interactive video tutorials with embedded editors.

## 🔧 Tools & Validators

* [W3C Markup Validation Service](https://validator.w3.org/): Check your HTML for errors and standard compliance.
* [Can I use](https://caniuse.com/): Browser support tables for HTML features.
* [Emmet Cheat Sheet](https://docs.emmet.io/cheat-sheet/): Speed up your HTML coding with Emmet abbreviations.

## 🧩 Reference & Cheat Sheets

* [HTML Cheat Sheet](https://htmlcheatsheet.com/): Quick reference for tags, attributes, and structure.
* [OverAPI HTML Reference](https://overapi.com/html): All-in-one cheat sheet for HTML.
* [DevDocs.io - HTML](https://devdocs.io/html/): Fast, offline-accessible developer documentation.
