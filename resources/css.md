## CSS Resources

### 📘 Official Documentation & References

* [MDN Web Docs - CSS](https://developer.mozilla.org/en-US/docs/Web/CSS): In-depth reference for all CSS properties and features.
* [W3C CSS Specification](https://www.w3.org/Style/CSS/current-work): Official specifications and drafts.
* [CSS-Tricks Almanac](https://css-tricks.com/almanac/): Easy-to-understand explanations of CSS properties and techniques.

### 🎓 Tutorials & Learning Platforms

* [freeCodeCamp - Responsive Web Design](https://www.freecodecamp.org/learn/responsive-web-design/): Learn CSS by building projects.
* [W3Schools CSS Tutorial](https://www.w3schools.com/css/): Beginner-focused with examples.
* [CSS-Tricks Guides](https://css-tricks.com/guides/): Deep dives into specific CSS topics.
* [The Odin Project - Foundations](https://www.theodinproject.com/paths/foundations/courses/foundations): Free, full curriculum with HTML and CSS.
* [Codecademy - Learn CSS](https://www.codecademy.com/learn/learn-css): Interactive lessons with browser-based coding.

### 🧠 Practice & Interactive Learning

* [Flexbox Froggy](https://flexboxfroggy.com/): Game to learn CSS Flexbox.
* [Grid Garden](https://cssgridgarden.com/): Game to learn CSS Grid.
* [CSS Battle](https://cssbattle.dev/): Challenge your CSS creativity.
* [Frontend Mentor](https://www.frontendmentor.io/): Build real projects and improve design implementation.

### 🔧 Tools & Utilities

* [Autoprefixer CSS Online](https://autoprefixer.github.io/): Automatically add vendor prefixes.
* [CSS Gradient](https://cssgradient.io/): Visual gradient generator.
* [Clippy](https://bennettfeely.com/clippy/): Shape builder for CSS clip-path.
* [Animista](https://animista.net/): Create custom CSS animations.
* [Can I use](https://caniuse.com/): Browser compatibility reference for CSS features.

### 🧩 Reference & Cheat Sheets

* [CSS Cheat Sheet](https://htmlcheatsheet.com/css/): Handy list of selectors, properties, and values.
* [OverAPI CSS Reference](https://overapi.com/css): All-in-one CSS reference.
* [DevDocs.io - CSS](https://devdocs.io/css/): Fast, searchable CSS documentation.
* [Flexbox Cheat Sheet](https://flexbox.malven.co/): Quick visual guide for Flexbox.
* [Grid Cheat Sheet](https://grid.malven.co/): Quick visual guide for CSS Grid.
